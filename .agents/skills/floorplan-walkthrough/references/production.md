# Blender 制作过程

这里记录实际制作房屋漫游时使用的方法，供另一个智能体按新图执行。完整过程是：读图校准 → 空间白模 → 运镜 → 分房间建模 → 材质灯光 → 展示动画 → 样帧与全程预览 → 正式帧序列 → 中文合成 → 验片。十秒预览按所需范围执行；正式成片继续完成可见细节。

## 一、建立本次项目

在独立工作目录保留下列产物。目录名可随环境调整，工程引用素材时优先使用相对路径。

```text
本次户型/
  输入/户型图.png
  layout.json                 已校准的空间和路线数据
  制作说明.md                 尺寸来源、假设、房间时间点与修改方法
  建模/                       本次生成的建模和细化脚本
  白模.blend
  成片.blend
  核对/                       俯视对图、路线图和关键样帧
  预览帧/
  正式帧/
  后期/cues.json
  后期/混音.wav               需要声音时提供
  户型漫游.mp4
```

同一套坐标转换、材质函数和基础几何函数由主脚本提供，各房间模块使用它们。房间模块只增加自己负责的集合和物体，主脚本统一建立相机、动画、输出设置。这样修厨房柜体时不必改客厅。

## 二、把图上的线变成空间

1. 读图中的已标尺寸，分清净尺寸、墙中心线尺寸和总尺寸。选一个清楚的角点作为原点，在说明里写清尺寸量到哪里。
2. 若已知图上长度为 `p` 像素、标注长度为 `L` 米，则 `s = L / p`。像素纵轴向下，三维 Y 轴向上，可用 `x = (u-u0)*s`、`y = (v0-v)*s` 转换。在另一个方向复核比例。斜拍图先校正透视。
3. 先搭地面、墙、门窗洞口、楼梯和主要家具占位。门洞与窗洞分上下沿，保留门楣和窗台。墙和家具尺度用米，矩形布局可采用 [布局格式](layout.md)。
4. 相机暂设正俯视，导出核对图；叠到原图上检查轮廓、墙线、独立尺寸、门窗和房间连接。记录差异，修正后再安排室内运镜。

资料不全时可推定层高、墙厚、门窗高度和装修，但要逐项记录。入口和连通关系有歧义时，先核实影响路线的部分。

## 三、把白模细化为室内场景

将白模另存 `成片.blend`。按「地面与墙体、门窗、各房间家具、固定木作、灯光、天花、相机」分集合。实际房间多时可再拆成厨房卫浴、客餐厅等建模模块。

| 对象 | 做法与观察点 |
| --- | --- |
| 地面和墙体 | 地板或地砖分块，接缝有真实宽度，墙角和踢脚线不悬空；剖切俯瞰有整洁的切边。 |
| 沙发、椅子、床 | 从体块定尺度，拆出坐垫、靠背、腿和扶手，用轻圆角表现软硬关系。检查和门、桌子的相对大小。 |
| 厨房与卫浴 | 补柜门、台面、水槽、灶具、龙头与洁具，优先做镜头看得到的分件。镜面和玻璃按实际效果设置。 |
| 门窗和固定木作 | 门框、窗框、玻璃、柜门与柜体分别建模；门扇用实际铰链位置设转轴，留出开合范围。 |
| 灯具与装饰 | 灯罩、灯芯和光源分开。装饰书封、挂画和电器标牌使用简体中文或无字素材。 |

脚本生成几何时，可用立方体、圆柱和球体组合。圆角宽度以物体实际尺寸为依据，先烘焙缩放再加倒角。细小五金与边线用少量边数即可；用合适的平滑或表面法线设置改善边缘。不要对所有物体直接套同一个大圆角。

## 四、材质和灯光

实际制作采用暖中性色墙面、木材、织物、暖灰石材和少量深色金属。新任务按其风格要求改色板。

- 色板若采用十六进制 sRGB，写入着色器线性色值时先转换：通道 `c≤0.04045` 用 `c/12.92`，其余用 `((c+0.055)/1.055)**2.4`。避免颜色因重复转换而变暗。
- 木材可用物体坐标，经不同轴向比例缩放接噪波和色带，得到沿板材方向的纹理；各板用稳定种子做轻微色差。织物和墙面主要靠粗糙度区分，金属、石材与玻璃分别调整反射和透射。
- 主光从实际窗洞方向进入，可在窗外放矩形面光。房间内部以大而弱的柔光维持暗部层次，厨房台面、卫浴和玄关再加局部照明。可见灯具的自发光和实际光源分别控制。
- 先渲染窗边、主要房间和暗过道，保持窗外高光与室内细节。确定颜色管理和曝光后再微调光源，避免每个房间用不同曝光补救。

灯光亮度、样本数和色彩管理以本次 Blender 版本及样帧为准。Eevee 与 Cycles 的反射、玻璃和间接光表现不同，切换引擎后重新看样帧。

## 五、相机路线与展示动画

### 步行路线

先画通路和停留点，再设相机位置与独立的注视点或朝向。室内视高以约 1.5–1.65 米作为起点，焦距按视野与空间选择，避免用极广角强行装下整个房间。窄门前后和拐角前后各设路径点；相机中心、镜头近处和门框一起检查。尽端房间要沿实际门洞退出。

基础工具使用线性插值，便于控制不越出路径；正式镜头可用有约束的缓入缓出，复查曲线中段是否切角穿墙。使用四元数时维持相邻关键帧的符号连续，使用欧拉角时处理跨越一圈的跳转。位置插值和转头速度分别看，不能只看少数关键帧。

### 俯瞰到室内

连续下降或切换相机均可。实际成片使用独立的正交俯瞰相机和透视步行相机，以时间轴标记绑定相机；步行段的走位、视线和焦距独立设置。切换前后检查构图，说明镜头是否包含切换，不把切镜描述成连续飞入。

```python
# camera_obj 为已经创建的相机；frame 按本片时间轴确定。
marker = scene.timeline_markers.new("步行入户", frame=frame)
marker.camera = camera_obj
```

开场俯瞰需要看清布局时，可暂时隐藏天花并使用展示底台；进入室内后显示天花、窗外环境和入户落地面，关闭会遮挡室内的展示背景。`hide_render` 与 `hide_viewport` 分别设置关键帧，并使用离散切换。仔细检查切换前后一帧，防止顶面突然挡住下降中的相机。

### 墙体升起与开门

- 墙体升起时让墙脚留在原地。对于原始网格高度 `H`、中心位于 `b + H/2` 的墙，缩放因子为 `k` 时设 `scale.z = k`、`location.z = b + k*H/2`。若上下沿都随整体示意比例变化，则使用 `location.z = k*(b+H/2)`。根据本次表达选一种，避免门楣与墙片脱节。
- 门扇与把手挂在铰链处的空物体下，保留世界变换后围绕该轴旋转。相机到门洞前完成开启；开门弧线不碰相邻墙体或家具。实际门洞很窄时，调整走位和拍摄方向。
- 墙体、门、相机和顶面显隐采用同一帧率和时序。第 1 帧对应时间零，图卡以输出第一张画面为时间零。

## 六、从样帧到成片

1. 先出俯瞰、入户门、转角、重点房间和暗处样帧，核对比例、遮挡、材质与曝光。新风格先在少量样帧上修到位。
2. 做低分辨率全程预览，正常速度看行进与转头。家具定稿和门动画加入后复查，不仅检查关键帧。
3. 测试几帧的实际耗时，确定正式分辨率、引擎、样本和降噪，再用 [渲染工具](finishing.md) 保存连续 PNG。实际成片采用 1280 × 720、每秒 24 帧，时长按路线安排；这些参数可随任务调整。
4. 用实际入画时间写 `cues.json`，标题写房间名，正文写一句画面或图纸能支持的信息。阅读时间不足时缩短文字或延长停留。对图卡和装饰中的文字逐项检查。
5. 按需求使用原创或有权使用的音乐、音效或旁白，先完成音量与淡入淡出，再合成 H.264、`yuv420p` 的 MP4。图卡在视频内烧录，便于其他设备回放。
6. 抽取全片画面总览，回看门洞、镜头切换和字幕切换，并正常速度完整播放。完整解码检查不能代替观看。重新打开工程验证材质、素材、相机标记与最后一帧。

只改图卡和声音时直接重合成；只改局部场景时渲染受影响范围，替换正式帧后重合成。改路线时同步复核房间入画时间，不能沿用旧图卡时序。

## 七、交付记录

`制作说明.md` 记录原图、标注与推定尺寸、装修假设、房间时间点、工程编辑入口、渲染设置、字体与素材信息、实际验片结果。白模和成片分别标识；缺失的装修与门窗细节要说明。工程、贴图、布局数据、脚本和成片共同组成可继续修改的交付物。
