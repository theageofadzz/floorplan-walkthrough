# 户型漫游

给定户型图，在 Blender 里重建空间并生成漫游。默认交付一段横屏视频、一份可编辑工程和一份简体中文说明。有时长、装修风格、重点房间或参考片时，按本次要求安排。用户只要短预览时，先验证路线与导览，再交付约十秒的片段。

1. **读图并记录尺寸。** 读外墙、隔墙、门窗、房名和标注尺寸。按标注校准比例，能取得两个方向的独立读数时也检查拉伸。用正俯视图叠对原图，核对外轮廓、户型连接和门窗。记录已知值、推定值和无法确认的部分。入户位置、通路等关键歧义会改变全片时，先完成其余可确认内容，再核实。
2. **构建工程。** 把读图结果和镜头关键帧写成 JSON。规则布局可用 [布局格式与搭建命令](references/layout.md) 生成可编辑白模。异形墙面、定制门窗或复杂层高可直接用 Blender 搭建，并沿用后面的验收顺序。
3. **先走通，再细化。** 俯瞰交代全局，下降至入户，再以步行视角沿实际洞口走进重点空间，有条件时从开阔处回望。把相机位置和朝向分别排好，过门和转角适当放慢。试播全程以发现穿墙或贴近门框，家具落位后复查。交付成片时，逐段完善墙地材质、门窗、家具、窗光和暗部细节，按 [画面制作与验收](references/production.md) 核对。
4. **加中文导览并导出。** 按空间实际入画的时刻写房名和一句有依据的说明，保证正常速度能读完。视频里的可见文字用准确自然的简体中文。用 [渲染和合成步骤](references/finishing.md) 输出带导览的完整视频；需要配乐或配音时随片长安排。
5. **复看并交付。** 以正常速度完整播放，检查重点空间、字幕、画面和声音是否连贯。重开工程确认素材能加载。交付视频、`.blend` 和中文说明，列出尺寸假设、房间时间点及修改相机和图卡的方法。按验证状态标明这是白模预览还是已细化并验收的成片。

工具需要 Blender、Python 3、支持所用滤镜的 FFmpeg 和本机可用的简体中文字体。路径由本次环境提供。输入、工作文件和输出放在本次项目目录。技能可仅凭本目录和新图使用。发布案例或素材按用户对本次交付的授权范围办理。
