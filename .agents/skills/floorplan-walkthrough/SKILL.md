# 户型漫游

本技能提炼自「按图重建房屋，再用 Blender 制作中文漫游影片」的实际流程。每个新户型都重新读图、建模和安排镜头。默认交付横屏影片、可编辑工程及中文说明；有时长、风格或重点房间要求时沿用本次要求。

## 开始前

- 检查本机 Blender、Python 3、带 `libx264` 和 `drawtext` 的 FFmpeg，以及覆盖简体中文的字体。通过后台 Blender Python 操作场景；需要用户查看或编辑时再打开工程。无需绑定某个专用连接器。
- 将新图、布局数据、建模脚本、工程、渲染帧和成片放入本次独立项目目录，保留可复现的输入。使用技能自身文件的路径时，从本 `SKILL.md` 所在目录解析。
- 先读 [Blender 制作过程](references/production.md)。生成规则布局时再读 [布局数据格式](references/layout.md)，准备渲染和导览时读 [渲染与合成](references/finishing.md)。

## 执行流程

1. **读图校准。** 从图上读取外轮廓、墙线、门窗、房间及连通关系。选择标注尺寸换算像素与米，复核另一方向，校正照片透视。把可确认值、推定值和影响通路的歧义写进 `制作说明.md`。关键歧义需核实，其余部分可继续。
2. **搭建并对图。** 输出 `layout.json` 与俯视核对图。规则户型可运行 `scripts/build_layout.py` 生成 `白模.blend`；不规则轮廓用网格补齐。该工具接收已读好的数据，图片由智能体解读。核对墙体、洞口与原图后，另存 `成片.blend`，随后在它上面继续细化。
3. **先走通路线。** 俯瞰交代全局，再到入户门，以步行视高穿过真实门洞进入重点空间。镜头位置、朝向与焦距分别调整，窄门和转角放慢，尽端房间原路退出。按用户片长制作低清全程或约十秒片段，检查穿模、遮挡和转头。
4. **完成室内画面。** 按房间组织可编辑集合与建模模块，将家具占位细化为带圆角、分件和正确尺度的物件。补门窗、柜体、台面、顶面和画面里看得见的细节。统一材质与程序木纹，安排窗光、各房间柔光和工作照明。渲染俯瞰、门口、重点房间和暗处样帧，比对参考再调整。
5. **编排展示动画。** 需要墙体升起或开门时，墙脚保持不动，门绕铰链转动，并在相机经过前完成动作。需要分开俯瞰与室内阶段时，用相机标记切换，联动天花和展示背景显隐。无此需求时保留简洁连续运镜。细化后重新检查门扇和家具占用的通路。
6. **渲染与中文后期。** 先用 `scripts/render_frames.py` 的预览配置估算耗时并看全程，再按成片设置输出连续 PNG。依据实际入画时间写 `cues.json`，用 `scripts/compose_video.py` 烧录简体中文导览，按要求加混好的音轨。字幕、书封、标牌等可见文字均用自然准确的简体中文；未确认的信息写明是演示设定。
7. **验片与交付。** 正常速度播放完整影片，检查空间顺序、过门和转身、字幕时机、暗部、窗边高光及声音。做全片画面总览，完整解码，再重新打开工程确认素材路径。交付视频、工程、输入数据和脚本、必要素材、中文说明及已检查的项目；明确白模预览和正式成片的状态。

## 返修和继续制作

改字幕或音乐只重合成；改局部材质或灯光时补渲受影响帧；改通路或门窗时复查相邻镜头与导览时间。已细化的工程继续在其副本上修改，避免重跑白模生成工具覆盖它。只生成白模不算完成正式成片；在用户指定的交付范围内继续制作、检查和修正。

`assets/practice-plan.svg`、`assets/practice-layout.json` 和 `assets/practice-cues.json` 是配套的虚构练习。它们用于验证工具链，制作新户型时以新图为依据。发布案例或素材按本次交付的授权范围办理。
