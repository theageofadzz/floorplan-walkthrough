# 用「户型漫游」技能把平面图做成视频

本教程面向第一次使用这套技能的人。你提供一张户型图和展示要求，智能体按技能里的方法操作 Blender：校准图纸、搭建空间、规划镜头、完善家具材质与灯光、制作中文导览，最后输出视频和可编辑工程。

技能入口是 [`SKILL.md`](../.agents/skills/floorplan-walkthrough/SKILL.md)。其中记录给智能体执行的步骤，辅助脚本负责重复的搭建、渲染与合成工作。你可以直接按下面的步骤给智能体发指令，也可以在文末用虚构户型练习命令。

## 第一步：准备电脑上的工具

| 工具 | 用来做什么 | 要确认什么 |
| --- | --- | --- |
| Blender | 建模、动画、灯光与渲染 | 本机可以启动；本仓库已在 Blender 5.3 验证。其他版本先运行练习，按实际报错调整。 |
| Python 3.9 或更新版本 | 合成导览与视频 | 终端能运行 `python3 --version`，Windows 常用 `py -3 --version`。Blender 内的建模脚本使用 Blender 自带 Python。 |
| FFmpeg | 把渲染帧和导览编码成视频 | 有 `libx264` 编码器，加中文导览时还需 `drawtext` 滤镜。 |
| 简体中文字体文件 | 显示视频中的汉字 | 使用本机可用的思源黑体、苹方或其他覆盖简体中文的字体。 |
| 能读图并操作本机文件的智能体 | 读取户型和执行技能 | 使用 Codex，或让其他智能体读取本教程链接的 `SKILL.md`。 |

这些工具在 macOS、Windows 和 Linux 上都可以准备。可先让智能体检查本机已有工具，并记录可执行文件和字体的实际路径。缺少的工具从各自官方发行渠道安装。运行本技能的三个脚本无需额外安装 Python 包。

可给智能体的准备指令：

> 检查本机 Blender、Python 3、FFmpeg 和简体中文字体是否可用。确认 FFmpeg 有 libx264 和 drawtext，列出实际路径。先完成检查，缺少什么再告诉我。

## 第二步：取得项目并让智能体找到技能

克隆公开仓库，或者从 GitHub 下载并解压项目：

```bash
git clone https://github.com/theageofadzz/floorplan-walkthrough.git
cd floorplan-walkthrough
```

在 Codex 中打开这个 `floorplan-walkthrough` 文件夹，并在该项目中新建任务。仓库已经把技能放在下面的位置：

```text
.agents/skills/floorplan-walkthrough/SKILL.md
```

在支持仓库技能发现的 Codex 中，可以用 `$floorplan-walkthrough` 调用。若当前界面没有显示技能，直接给出指令：

> 读取 `.agents/skills/floorplan-walkthrough/SKILL.md`，按其中的流程执行接下来的户型漫游任务。

要在另一个项目复用时，把本仓库的 `.agents/skills/floorplan-walkthrough/` 整个目录复制到那个项目的 `.agents/skills/` 下，保留内部的 `scripts`、`references`、`assets` 和许可文件。其他智能体可从同一个 `SKILL.md` 读取流程，再使用本机可用的 Blender 控制方式执行。

## 第三步：附上你的户型图

在任务里附上清楚的户型图片，或告诉智能体图纸在项目里的路径。PDF 可以提供包含户型的页码。优先使用能看清房间名、门窗和尺寸线的原图。

有下列资料时一并提供：

- 至少一个已知尺寸；若两个方向都有独立尺寸，更便于检查图片是否变形。
- 入户位置、门的开启方向和层高等信息。
- 装修参考、想重点看的房间，以及视频用途和时长。

无尺寸的图也能做演示。智能体会按相对比例搭建，把选定的层高、墙厚、门窗尺寸等写入说明，方便你之后校正。原图上难以辨认的入口或通路要先核实，否则会影响整条路线。

## 第四步：复制这段提示词开始制作

附图后发送：

> 用 `$floorplan-walkthrough` 把我附上的户型图做成全屋漫游视频。请按本次图纸重新校准尺寸、门窗和房间连接，把确定的数据和演示假设写清楚。先生成约 10 秒的低清预览并自查布局、过门和转弯，再继续完成整套户型的漫游。开场俯瞰交代格局，随后从入户门以步行视角参观重点空间。装修采用暖色现代家居，画面导览和可见文字使用准确自然的简体中文。正式成片至少 1280 × 720、每秒 24 帧，时长按完整路线安排；交付视频、可编辑 Blender 工程、必要素材与中文制作说明。所有产物放进 `我的户型漫游/`，并告诉我预览、成片和工程分别在哪。

你只想先看十秒时，把其中「再继续完成整套户型的漫游」改为「这次先交付十秒预览和对应工程，后续再精修」。时长很短时可只选一个重点空间，保留足够的观看和阅读时间。

## 第五步：看每个阶段的结果

智能体应按下面的顺序推进。实际房间数量和文件组织可随户型调整。

| 阶段 | 智能体在 Blender 中做什么 | 你可以看什么 |
| --- | --- | --- |
| 读图与校准 | 把墙线、洞口和家具位置转换为米制坐标，建立房间连接关系 | 已知尺寸、推定尺寸，以及模型正俯视图与原图的对照。 |
| 空间草稿 | 建地面、内外墙和真实洞口，用体块预留家具和通路 | 外轮廓是否一致，门窗与房间是否对得上。 |
| 镜头预览 | 从俯瞰过渡到入户，分别安排相机走位与朝向，沿实际通路参观 | 十秒预览和路线图，重点看过门、转向、镜头视高与家具遮挡。 |
| 画面精修 | 加门窗和家具细节，设材质、窗光、室内补光及需要的墙体或开门动画 | 俯瞰、入户、主要房间和较暗位置的关键样帧。 |
| 渲染与后期 | 输出连续图片，按实际入画时间加入中文导览和需要的音轨 | 完整视频、画面总览、图卡和配乐。 |
| 验收与打包 | 通看全片、复查文字与穿模，重开工程核对素材路径 | 可播放成片、可继续编辑的工程和中文说明。 |

空间草稿使用基础几何和灯光，适合检查比例和通路。要接近仓库中[完整客餐厅样片](https://theageofadzz.github.io/floorplan-walkthrough/preview/)的效果，还需要完成精修、关键样帧比对和全片验收；这一部分由智能体按新户型继续制作。

## 第六步：提出具体修改

用空间、时间点和你想改变的结果描述修改，智能体就能定位到对应阶段。

| 你想修改的内容 | 可直接发送的指令 |
| --- | --- |
| 尺寸或门窗 | 「客厅进深应为 4.2 米，厨房门在隔墙右侧。请更新布局，检查受影响的家具和镜头路线，再补渲对应片段。」 |
| 装修风格 | 「保留户型和路线，把客厅改成浅木色与暖白墙面。先出客厅和玄关两张样帧，再把确认后的风格用到其他房间。」 |
| 运镜节奏 | 「第 6 秒进门太快，请在门洞前减速，进入客厅后多停两秒，并同步调整导览时序。」 |
| 中文文案 | 「把客厅说明改成『沙发与餐厅之间保留通行空间』，检查这句是否符合画面，用已有渲染帧重新合成。」 |
| 配乐或音量 | 「保留画面与图卡，换用我提供的配乐，开头结尾淡入淡出，再导出完整视频。」 |

模型和镜头变化通常需要重渲受影响的画面；只改图卡、文案或音轨时，可复用已有图片重新合成。精修应在已有工程上继续保存新版本；重新运行白模生成器会创建一份新的基础工程。

## 第七步：找到并检查交付文件

若使用上面的提示词，智能体应把结果放进 `我的户型漫游/`。打开实际交付的视频，以正常速度从头看到尾，再打开 `.blend` 确认能继续编辑。中文制作说明应给出实际文件名和修改入口。

交付时重点核对：

- 画面中的房间、入口和门窗能与原图对应，假设尺寸有记录。
- 相机沿实际通路经过门洞，不穿墙、门扇和家具。
- 图卡在对应空间入画后出现，中文准确可读，没有缺字。
- 视频完整可播；使用音轨时，声音清楚且无明显过载。
- 工程能重新打开，外部贴图、字体和其他必要素材的位置有说明。

## 用随附虚构户型练习一次

这一步用来检查工具和命令是否跑通。随附的[练习平面图](../.agents/skills/floorplan-walkthrough/assets/practice-plan.svg)与[布局数据](../.agents/skills/floorplan-walkthrough/assets/practice-layout.json)相互对应，和用户提供的真实户型无关。练习输出为十秒基础空间预览，便于理解数据、工程、帧和视频之间的关系。

### 1. 让智能体代跑

不想操作终端时，在项目里发送：

> 用 `$floorplan-walkthrough` 的随附练习户型验证环境。从 `assets/practice-layout.json` 生成可编辑工程，用预览设置渲染全部 240 帧，再按 `assets/practice-cues.json` 加入中文导览，导出十秒视频。把结果放进 `build/practice/`，告诉我如何打开。

### 2. 或按命令运行

下面的命令从仓库根目录执行，采用 macOS / Linux 的终端语法。请将工具和字体变量改为本机实际路径；若终端已经能找到 Blender 或 FFmpeg，也可以直接写 `blender` 或 `ffmpeg`。

```bash
SKILL_DIR="$PWD/.agents/skills/floorplan-walkthrough"
BLENDER="/Applications/Blender.app/Contents/MacOS/Blender"
FFMPEG="ffmpeg"
CJK_FONT="/System/Library/Fonts/STHeiti Medium.ttc"

"$BLENDER" -b --factory-startup --python-exit-code 1 \
  --python "$SKILL_DIR/scripts/build_layout.py" -- \
  --layout "$SKILL_DIR/assets/practice-layout.json" \
  --output build/practice/漫游草稿.blend

"$BLENDER" -b build/practice/漫游草稿.blend --python-exit-code 1 \
  --python "$SKILL_DIR/scripts/render_frames.py" -- \
  --output build/practice/frames --preset preview

python3 "$SKILL_DIR/scripts/compose_video.py" \
  --frames 'build/practice/frames/%04d.png' --fps 24 \
  --cues "$SKILL_DIR/assets/practice-cues.json" --font "$CJK_FONT" \
  --ffmpeg "$FFMPEG" --output build/practice/户型漫游预览.mp4
```

预览预设把练习的 1280 × 720 画面按 25% 输出为 320 × 180，默认使用处理器渲染 12 个采样。需要看清更多细节时，可在渲染命令末尾加 `--scale 50`，得到 640 × 360 的预览。重新渲染时使用新的输出目录，或确认可替换已有帧后传入 `--overwrite`。帧目录包含 `0001.png` 至 `0240.png` 和 `render-info.json`；240 帧除以每秒 24 帧，正好十秒。

Windows 可在 PowerShell 中设置路径并调用同一组脚本。下面是等价命令；Blender 的安装文件夹和字体路径按本机情况替换：

```powershell
$SKILL_DIR = Join-Path $PWD '.agents/skills/floorplan-walkthrough'
$BLENDER = 'C:\Program Files\Blender Foundation\Blender 5.3\blender.exe'
$FFMPEG = 'ffmpeg'
$CJK_FONT = 'C:\Windows\Fonts\msyh.ttc'

& $BLENDER -b --factory-startup --python-exit-code 1 --python "$SKILL_DIR/scripts/build_layout.py" -- --layout "$SKILL_DIR/assets/practice-layout.json" --output 'build/practice/漫游草稿.blend'

& $BLENDER -b 'build/practice/漫游草稿.blend' --python-exit-code 1 --python "$SKILL_DIR/scripts/render_frames.py" -- --output 'build/practice/frames' --preset preview

py -3 "$SKILL_DIR/scripts/compose_video.py" --frames 'build/practice/frames/%04d.png' --fps 24 --cues "$SKILL_DIR/assets/practice-cues.json" --font "$CJK_FONT" --ffmpeg "$FFMPEG" --output 'build/practice/户型漫游预览.mp4'
```

修改练习布局时参考[布局字段说明](../.agents/skills/floorplan-walkthrough/references/layout.md)。修改图卡或添加混好的音轨时，参考[中文导览与视频合成](../.agents/skills/floorplan-walkthrough/references/finishing.md)。处理真实户型时，由智能体重新读图生成本次数据，再沿用这一组构建、渲染和合成工具。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 技能没有出现 | 确认打开的是包含 `.agents/skills/` 的项目；让智能体明确读取技能入口，或在正确项目中新建任务。 |
| 找不到 Blender / FFmpeg | 使用工具的实际可执行文件路径，并给含空格的路径加引号。FFmpeg 也可用合成脚本的 `--ffmpeg` 指定。 |
| 没有可用图形处理器 | 先用处理器预览预设。正式渲染根据本机可用设备设置引擎，再验证关键样帧。 |
| 导览缺字或显示方框 | 换用覆盖简体中文的实际字体文件，重新合成并看一帧确认。 |
| FFmpeg 提示缺少 `drawtext` 或 `libx264` | 换用包含相应滤镜和编码器的 FFmpeg，再运行合成命令。 |
| 合成提示缺帧或时序越界 | 根据 `render-info.json` 检查输出帧范围和帧率，补齐缺帧，或修改图卡起止时间。 |
| 画面只有基本墙体和家具块 | 当前是空间草稿。让智能体按[制作与验收流程](../.agents/skills/floorplan-walkthrough/references/production.md)继续完善门窗、家具、材质与灯光。 |
| 十秒放不下所有房间 | 精简重点空间或延长路线时长，同时更新相机关键帧、图卡和音轨。 |
