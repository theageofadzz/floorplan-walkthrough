# 客餐厅漫游

这个案例用 48 秒展示从一张户型平面图重建的客餐厅。影片配有简体中文导览和原创配乐。

[在线播放](https://theageofadzz.github.io/floorplan-walkthrough/preview/) · [下载完整视频](../../docs/preview/living-dining.mp4?raw=true)

| 时间 | 画面 |
| --- | --- |
| 0–5 秒 | 从上方看清客厅、餐厅、厨房和折返楼梯的位置。 |
| 5–13 秒 | 从右侧入户，经过玄关。 |
| 13–19 秒 | 看玄关旁的卫生间。 |
| 19–27 秒 | 经过餐桌，看到客厅与厨房的连接。 |
| 27–34 秒 | 进入厨房，看沿相邻两面墙布置的灶台和水槽。 |
| 34–42 秒 | 穿过客厅，走向左侧窗边。 |
| 42–48 秒 | 从窗边回望客餐厅。 |

建模沿用图上标注的总宽，进深按图面比例估算。层高、门窗高度、开门方向、灯光和装修材质按演示设定。拿到新户型后，可以参考[制作流程](../../制作流程.md)核对比例、设计路线和编排导览。

视频和截图用于展示本案例。仓库的 [MIT 许可](../../LICENSE)适用于代码和文档。
